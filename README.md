
# Patient Appointment Management System

## Overview
A Java console application for managing patient appointments.

## Features
- Add appointments
- View appointments
- Search appointments
- Cancel appointments
- Save appointment data locally

## Technology
- Java
- File handling
- Command-line interface

## How to Run

Compile the program:

```bash
javac AppointmentSystem.java
```

Run the program:

```bash
java AppointmentSystem
```

## Purpose
This project demonstrates Java programming, input handling, and basic appointment management.
